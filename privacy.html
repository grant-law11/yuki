Mom AI privacy policy

Last updated 17 October 2026.

Mom AI is a private home assistant used by one family. It is not offered to the public.

What Google data it uses

With the calendar owner's permission, Mom AI reads events (date, time and title) from the Google Calendars the owner chooses, so they can be shown on the home screen. It adds an event to the calendar only after the person at the screen has seen the event and confirmed it.

Where the data goes

Calendar data is fetched by a computer in the family's home and shown on the family's own touchscreen. It is kept only as a short-lived copy for display. It is not sold, not shared with anyone, not used for advertising, and not used to train AI models.

The sign-in key from Google is stored only on that home computer and is never shown on screen or sent anywhere else.

Google API Services User Data Policy

Mom AI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The calendar owner can withdraw Mom AI's access at any time at myaccount.google.com/permissions. The home copy of the calendar is then discarded.
